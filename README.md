# **Auto Insurance Fraud Detection System using ML & Generative AI**

![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)

## **Project Overview**

The **Auto Insurance Fraud Detection System** leverages **Machine Learning (ML)** for predicting fraudulent insurance claims and **Generative AI** for enhanced data insights. This system is fully integrated into an interactive **Streamlit** application where users can input insurance claim details, ask data-driven questions, and view predictive results and visualized insights.

All results, including **fraud predictions** and **data insights**, are presented directly within the **Streamlit app**. The project uses advanced techniques like **Natural Language-to-SQL** with **LangChain** and **Generative AI** powered by **Ollama** to retrieve data-driven insights from a **PostgreSQL** database.

---

## **Key Features**

1. **Fraud Prediction**:
   - Uses a trained **Machine Learning model** to predict whether an insurance claim is **fraudulent** or **genuine** based on user input.

2. **Data Insights**:
   - Allows users to ask **data-driven questions** in **natural language**. The system generates **SQL queries** using **LangChain**, queries the **PostgreSQL** database, and displays the results.

3. **Interactive Dashboards**:
   - **Metabase** is used to generate interactive dashboards. These dashboards are embedded in the **Streamlit** app to show data trends, fraud detection patterns, and analytics.

4. **Generative AI**:
   - Uses **LangChain** for **Natural Language-to-SQL** transformation and **Ollama** for conversational AI capabilities, enabling users to interact with the system intelligently.

5. **User Interface**:
   - Provides an interactive and user-friendly interface where users can input claim details, receive predictions, and explore insights through visualizations.
